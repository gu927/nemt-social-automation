# NEMT Social Automation for SpeedCare Transportation

## Weekly Content Calendar

- **Monday**: Healthcare transportation tip  
- **Tuesday**: Motivational/professional quote  
- **Wednesday**: Wheelchair safety fact  
- **Thursday**: Community/facility appreciation  
- **Friday**: Behind the scenes / van photo (suggests uploading real photos)  
- **Saturday**: Patient care/service message  
- **Sunday**: Company mission/family business post

Posts are professional, trustworthy, and healthcare-focused for Bakersfield area.

## Setup
1. Add FB_PAGE_ID and FB_PAGE_ACCESS_TOKEN secrets
2. (Optional) Add real van photos to /images folder
